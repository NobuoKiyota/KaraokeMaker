# カラオケ・バンド練習用動画自動生成アプリ（KaraokeMaker）実装計画

ExcelのタイミングシートとWAVファイルから、歌詞・コード・小節数が音楽に同期して動くカラオケ・バンド練習用動画（MP4）を自動生成するPythonデスクトップアプリを開発します。

本計画書をご確認いただき、フィードバック・ご承認をお願いいたします。

## 概要と目的

ユーザー様が用意される **Excelタイミングデータ** と **WAVオーディオファイル** をインプットとし、以下の特徴を持つ動画を自動生成・プレビューするデスクトップアプリを開発します。

- **テンポ同期**: BPM情報に基づき、小節と拍の正確な時間を算出。
- **2行交互歌詞表示＆カラオケワイプ**: 歌唱タイミングに合わせて文字色が左から右へ変わるワイプ処理。
- **コード進行・小節表示**: バンド練習に不可欠な「現在コード」「小節番号」を視覚的に分かりやすく配置。
- **GUIプレビュー機能**: WAVを再生しながら、実際の動画と同じ見た目をリアルタイムにプレビュー。

---

## 提案する改善点・拡張機能

サウンドデザイナーおよび楽器練習者としての利便性を最大化するため、以下の機能を提案し、初期実装に盛り込みます。

1. **ビジュアル・ビート・インジケーター（メトロノーム）**:
   - 画面上部または隅に、現在の「拍（1, 2, 3, 4）」をテンポ同期で点滅点灯するランプを配置。ドラムカウントや小節の入りを視覚的に捉えやすくします。
2. **小節グリッド付きコードタイムライン**:
   - 現在のコードだけでなく、「次の小節のコード」が事前に視覚的に分かるミニタイムラインを画面上部に表示。バンド練習用のリードシート（楽譜）的な役割を果たします。
3. **フォント・スタイルカスタマイズ機能**:
   - 歌詞フォント、フォントサイズ、待機文字色、ワイプ文字色、アウトライン（縁取り）の太さ・色をGUI上でカスタマイズし、プロファイルとして保存・読み込み可能にします。
4. **動画サイズ（アスペクト比）への自動追従**:
   - プレビュー画面とエクスポート動画で同じ描画エンジンを使用し、サイズ（1920x1080等）に応じて自動で位置やフォントスケールを調整。
5. **高速レンダリング（FFmpegパイプ接続）**:
   - 一時的な画像ファイルをディスクに書き出すことなく、Pillowで生成したフレーム画像をFFmpegのサブプロセスに直接パイプ経由で書き込むことで、ディスク負荷を抑え、レンダリングを高速化します。

## システム構成・使用ライブラリ

Python 3 環境で、以下のライブラリを活用して開発します。

- **GUI**: `PySide6` (Qt for Python)
  - タイムラインコントロール、WAV再生との同期、パラメータ設定画面。
- **Excel解析**: `openpyxl` & `pandas`
  - シート構造のスマートなパース、BPM/タイトル等のメタデータ抽出。
- **音声再生＆同期**: `sounddevice` & `soundfile`
  - プレビュー再生時の超低遅延再生と、シークバーとの同期。
- **画像・フレーム描画**: `Pillow` (PIL)
  - 日本語フォント、縁取りテキスト、アルファマスクを用いた正確なカラオケワイプ（色変化）の描画。
- **動画生成**: `ffmpeg`（サブプロセス呼び出し）または `imageio-ffmpeg`
  - 画像フレームとWAV音声を結合して高画質なMP4を生成。

## 歌詞のワイプ（カラオケ描画）ロジック詳細

1. **フレーズの構築**:
   - `Line: 1` または `Line: 2` ごとに、時間順で並んだ歌詞をマージして「文」を作ります。
   - 例: `[の中の神様, が, きみの, 運命決めたの, か, 毒の]` -> `"の中の神様がきみの運命決めたのか毒の"`
2. **文字境界の計算**:
   - Pillowの `ImageFont.getbbox()` または `getlength()` を使い、各部分テキストの描画幅をピクセル単位で事前に計算します。
   - 例: `"の中の神様"` の幅 $w_1$、`"が"` の幅 $w_2$ などを累積し、フレーズ全体の各文字・単語の位置を算出します。
3. **ワイプ位置（X座標）の決定**:
   - 現在時刻 $T$ において、歌唱中の部分テキスト $i$ の進行度 $\alpha = (T - t_{start}) / (t_{end} - t_{start})$ を求め、その部分テキストの描画開始X座標から終了X座標までの間で線形補間します。
4. **マスク描画**:
   - 同じフレーズテキストを、同じフォント・座標で2回描画します。
     1. ベース：待機色（例: 白、グレーのアウトライン）で全体を描画。
     2. ワイプ：歌唱後色（例: 赤、オレンジのアウトライン）で描画するが、ワイプX座標より左側のみを有効にするマスクを適用して重ね書き（または `Image.composite`）します。
   - これにより、文字の途中（例: 「あ」の左半分だけ赤、右半分は白）といった非常にスムーズなカラオケワイプが実現します。

## Verification Plan (検証計画)

### 自動テスト / ユニットテスト
- `test_parser.py` を作成し、サンプルExcelから正しい時間、歌詞フレーズ、コード進行がパースできるかをテスト。
- `test_renderer.py` を作成し、特定の秒数における画像が正常に生成され、エラーが出ないかをテスト。

### 手動テスト / 動作確認
1. アプリを起動し、`karaokemaker_sample.xlsx` と `test.wav` を読み込みます。
2. プレビューを再生し、WAVの音と画面のメトロノーム、歌詞ワイプ、コード進行が完全に同期して動くことを確認します。
3. シークバーをドラッグして、任意の場所にジャンプした際にプレビューが即座に追随することを確認します。
4. フォントサイズや色を変更し、リアルタイムにプレビューへ反映されることを確認します。
5. 「動画エクスポート」を実行し、進捗バーが100%になるまで正常に動作し、生成されたMP4動画をメディアプレイヤーで再生してズレがないか確認します。

> [!NOTE]
> 実装を開始する前に、以下の点についてご意見やご希望をお聞かせください。

1. **フォントについて**:
   - Windows標準で日本語が綺麗に表示される「MS ゴシック」「游ゴシック」「メイリオ」などを初期値とする予定ですが、お好みのフォント指定や、GUI上でPC内の任意のフォントファイル（.ttf / .otf）を選択できる機能は必要でしょうか？
2. **拍子（Time Signature）の想定**:
   - 今回のサンプルは4拍子（1小節=4拍）ですが、3拍子やその他の拍子への切り替え、あるいはExcelファイル側から自動判別（または指定）する機能は必要でしょうか？（初期実装としては、ExcelのヘッダまたはGUI上で拍子を設定できるように設計するのが安全と考えています）
3. **コード表示・メトロノームのデザイン**:
   - コード表示やビートインジケーター（拍のランプ点滅）は画面上部にシンプルに配置する予定ですが、デザイン面でのこだわり（CubaseのようなDAWのタイムライン風、または一般的なカラオケ画面風など）についてご要望はございますか？
