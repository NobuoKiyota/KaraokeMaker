# 楽譜風レイアウト・Excel編集・ドッキングUI拡張 実装計画

ユーザー様からいただいた理想のレイアウトおよび機能拡張のご要望に基づき、アプリをプロ仕様の「楽譜風タイミングエディタ＆カラオケジェネレーター」へ大幅に拡張します。

本計画書をご確認いただき、フィードバック・ご承認をお願いいたします。

## 予定される追加機能と改善点

### 1. 楽譜（リードシート）風のタイミング追従レイアウト
歌詞の真上に「小節番号」および「コード」がピタッと縦に並んで表示されるレイアウトを実装します。

- **描画ロジックの刷新**:
  - 歌詞フレーズを描画する際、Pillowで各ワード（「画面」「の中の神様」「が」等）の描画開始X座標（ピクセル）を計算します。
  - そのワードの開始タイミング（小節・拍）および指定されているコードを、ワードのX座標に合わせて真上に位置揃え（アライメント）して描画します。
  - 例（表示ライン①）:
    ```text
    18            19                            20             21
                  Gm                            Cm7            D
    [画面]        [の中の神様]                  [が]           [君の運命決めたのか]
    ```
    ※歌詞のフォントサイズ、コードのフォントサイズ、小節番号のフォントサイズ、それぞれのY方向のオフセット（間隔）はGUI上からピクセル単位でリアルタイムに微調整できるようにします。

### 2. アプリ内Excel編集機能（タイミングテーブル）
Excelを開かなくても、アプリ内でタイミング情報を追加・修正し、Excelファイルへ書き戻せる機能を実装します。

- **QTableWidget によるスプレッドシート風 UI**:
  - `小節`, `拍`, `セクション`, `コード`, `歌詞`, `表示行` の6列からなる編集可能なグリッドテーブル。
  - **行の追加・削除機能**: 任意の場所に行を挿入、または削除可能。
  - **Excel上書き・別名保存**: `openpyxl` を用いてテーブルの内容をExcelファイル（.xlsx）として直接保存。
  - **プレビュー連動**: テーブルの行を選択すると、WAVの再生位置がその小節・拍のタイミング（秒）へ自動シークする機能。

### 3. ドッキングウィジェット（QDockWidget）によるプロ仕様レイアウト
画面を広く使い、マルチモニター環境にも対応できるよう、各パネルをウィンドウから引き剥がして別窓化、またはドッキングできるレイアウトにします。

- **ドック化するパネル**:
  1. **編集テーブルドック**: タイミングデータのグリッドテーブル（画面下部または別窓に広く配置推奨）。
  2. **スタイル設定ドック**: フォントサイズ、色、Y座標位置などのパラメータ調整パネル。
  3. **ログコンソールドック**: プロセスの進捗ログ表示エリア。
- **メイン領域（Central Widget）**:
  - 大型のプレビューキャンバスと再生・シークバーコントロールのみを配置。

## Verification Plan (検証計画)

### 手動テスト / 動作確認
1. アプリを起動し、Excelタイミングデータをロードします。
2. ドッキングパネル（テーブル、スタイル設定）をドラッグして別窓化し、元の位置に再ドッキングできるか確認します。
3. タイミング編集テーブルで、歌詞やコードを書き換え、行を追加/削除します。
4. 「保存」を実行し、タイミングExcelファイルが正しく更新されていることを確認します。
5. スタイル設定で、歌詞ライン1・2の高さ、コード・小節とのオフセットスライダーを操作し、プレビュー上の楽譜風レイアウトがリアルタイムに整うことを確認します。
6. レンダリングを行い、出力されたMP4動画で、ユーザー様が指定された理想通りの「コード・小節追従歌詞レイアウト」が実現していることを確認します。
